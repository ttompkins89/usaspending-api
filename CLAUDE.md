# USAspending API Reference

Independent developer docs for the USAspending API, organized around the usaspending.gov pages each endpoint powers and styled with usaspending.gov's own design tokens. Deployed at https://usaspending-api.vercel.app from `main` on Vercel. Public repo. Not affiliated with the U.S. Treasury or USAspending.gov.

## Commands

- `npm run build`: runs `prebuild` (tokens, docs, resources), then `next build`. Every generator falls back to the committed file if its source can't be reached.
- `npm run tokens`: regenerate `tokens/usaspending.json` and `app/tokens.css` from the site's `src/_scss/core/_variables.scss`. `SITE_SCSS=<path>` uses a local copy.
- `npm run docs`: regenerate `lib/docs.json` from the latest contracts. `CONTRACTS_DIR=<path>` (plus `CONTRACTS_SHA`) uses a local copy.
- `npm run resources`: regenerate `lib/releases.json` (site Release Log wiki), `lib/changelog.json` (contract git history; `CONTRACTS_GIT=<clone>` locally), `lib/glossary.json` and `lib/dictionary.json` (from the API).

## Where content comes from

- Endpoint pages: generated only. Never hand-edit `lib/docs.json`; fix `scripts/build-docs.mjs` or `scripts/feature-map.mjs`.
- Feature for each endpoint: `scripts/feature-map.mjs`. First matching rule wins. Anything in "Other endpoints" is a bug in the map.
- Guides: call order in `lib/guides.ts`, traced from usaspending-website source files listed on each guide; intros in `content/guides/*.md`.
- Hand-written pages: `content/*.md` and the page components under `app/`.
- Release notes, changelog, glossary, data dictionary: generated by `scripts/build-resources.mjs`. Don't edit the JSON.
- Tolerated upstream slips (undefined or mis-capitalized types, missing URLs, undeclared path parameters) are handled in the generator and shown as contract notes. Add a note for any new one.

## Design

- Colors come only from `--c-*` roles in `app/tokens.css`, which map (in `tokens/semantic.json`) to the site's own USWDS token names. Never hard-code a hex value in a component.
- Light and dark themes: `:root[data-theme='dark']`. The inline script in `app/layout.tsx` sets the theme before paint.
- Type: Source Sans 3 (the site's family) and Source Code Pro. Spacing on the 8px USWDS unit scale in `app/globals.css`.
- Shell: top bar (wordmark, Independent tag, search, Try the API, theme), left nav from `lib/nav.ts`, on-this-page rail with scroll-spy.
- Every text and fill pair meets WCAG AA in both themes. Real `<button>`, `<a>`, `<label>` elements. Visible focus ring.

## Guardrails

- Never use the USAspending.gov logo, the U.S. flag, the "official website of the United States government" banner, or anything implying this is a government product. The footer disclaimer stays on every page.
- The live console only proxies to `https://api.usaspending.gov/api/v2/`. Never widen the proxy to other hosts.
- No secrets. The API needs no keys.

## Voice

Plain, specific, short. Lead with what the endpoint does and which site page uses it. No em dashes. Sentence case headings. No filler words like "simply" or "just."
